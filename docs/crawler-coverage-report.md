## 3. 자동/수동/포기 판정 기준 (재사용 가능한 원칙)

| 유형 | 특징 | 판정 |
|---|---|---|
| 정적/렌더 후 **URL이 DOM에 노출** | Cafe24·Godomall·Shopify·타이틀리스트·지포어 | **자동 가능** (저비용) |
| **React onClick + 사설 API** | 버킷스토어·더카트·코오롱몰 | 고비용·저확실성 → 수동/포기 |
| **강한 봇보호** | 나이키 | 차단 리스크 → 포기 |
| **봇차단·비활성 엔드포인트** | 풋조이(410) | 수동 |
| **외부몰 리다이렉트** | 보스골프→golfnuts | 소스·브랜드 안전성 문제 → 스킵 |

버킷스토어 3브랜드가 향후 필요하면: RSC 페이로드 파싱 또는 카드 클릭-내비 캡처 = 별도 심화 작업(불안정). 우선순위 발생 시 별도 지시 요망.
