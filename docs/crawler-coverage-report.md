## 2. Playwright 1~4 트랙 실측 결과

| 대상 | 실측 난이도 | 결과 |
|---|---|---|
| 타이틀리스트 | 중 | ✅ 렌더 후 `/product/{CODE}` 링크 노출, `.item-name`·`[class*=price]` 파싱 |
| 지포어 | 중 | ✅ 렌더 후 `/Product/{CODE}` 노출, og:title(브랜드\|상품명) nameRegex + 가격 JS priceRegex |
| 보스골프 | **상+ → 스킵** | iamtom.co.kr 렌더해도 13KB 셸, 상품 미노출. 유일 링크가 외부 golfnuts.co.kr(cafe24) — **소스 불명확·브랜드 매핑 위험**. |
| 버킷스토어(3브랜드) | **상+ → 스킵** | 렌더는 되나 상품 카드에 **href·onclick·data 없음**(React onClick 내비), `/bucketapi/`에 **상품 목록 API 없음**(RSC 페이로드에만 존재). URL 추출 불가. |

**공통 인프라**(PlaywrightAdapter: 렌더→generic 파서 재사용)는 완성·배포됨. Playwright는 **로컬/Actions 전용**(Railway 금지).

## 3. 5~8번 진행/포기 권고 (실측 근거)

버킷스토어(초기 "중" 추정)가 실측 **상+**(URL 미추출)로 판명된 점에서, 5~8은 대체로 그 이상 난이도로 추정:

| 대상 | 권고 | 근거 |
|---|---|---|
| 더카트 | **보류/수동** | Phase 1에서 상품 sitemap 없음·정적 링크 없음. 버킷스토어처럼 React SPA일 가능성 높아 URL 추출 난망. 착수 전 1회 렌더 정찰로 확인은 가능하나 기대 낮음. |
| 랑방블랑(더한섬) | **보류** | 더한섬 대형 플랫폼 브랜드관 SPA. 내부 API 필요, 비용 대비 1개 브랜드. |
| 왁(코오롱몰) | **포기 권고** | 대형몰 SPA·무한스크롤·내부 API. 유지보수 비용 큼. |
| 나이키골프 | **포기 권고** | 강한 봇보호. Playwright도 차단 가능성 높음, 실패 리스크. |

**총평:** 정적/렌더 후 **URL이 DOM에 노출되는 사이트**(타이틀리스트·지포어)는 저비용. **React onClick+사설 API**형(버킷스토어·더카트·코오롱몰) 및 **봇보호**형(나이키)은 고비용·저확실성 → **수동 등록 또는 별도 심화 프로젝트**로 분리 권고.
- 버킷스토어 3브랜드가 필요하면: RSC 페이로드 파싱 or 카드 클릭-내비 캡처 = 별도 심화 작업(불안정). 우선순위 높으면 지시.
